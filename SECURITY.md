# Security policy

## Supported version

The latest commit on `main` is the supported development version.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the repository owner. Include reproduction
steps, affected endpoints, and potential impact. Do not include real customer data, credentials,
call audio, or provider secrets.

## Demo-data boundary

This repository contains synthetic organizations, agents, calls, network ranges, and credentials.
It intentionally stores no call audio and no real provider configuration. The demo password must
never be reused outside a local environment.
